# 墨路远征 · 三笔成阵

2026-09-05。首页 → **墨路远征** → 选择小队 → 落笔启程 → 取一枚墨契 → 择路 → 踏入战场。

## 战斗重新从墨量出发

远征中不再使用个人 SP 或技能冷却。双方每轮各有 3 墨；每名角色至多行动一次，技能花费 1～3 墨。
点人物查看技能，点技能并确认目标才支付墨量。ESC 取消目标，可以换另一人重新安排这一笔。

- **1 + 1 + 1**：三人接力。三叠浪会强化第三人的伤害与治疗。
- **1 + 2**：先铺垫，再以重招收锋。
- **3**：把整轮交给一道杀招。一字千钧会强化这类起手。
- **收笔**：把余墨化为全队护盾；每墨每人 7 点，单次每人最多 28 点。留白成壁提高转换效率。

所有人的状态与回合被动在该方一轮开始时推进一次。连携不会额外消耗持续时间。
对方第一招提前公开并承诺执行；阵亡目标可以合法重选，后续招式会根据局面应变。
灵能扰乱对没有免疫的目标必定生效：下次伤害与治疗降低 40%，护盾、净化与增益仍可正常使用。
数字以 `src/core/ink-turn.js`、`src/core/combat.js` 为准。

8 个原回蓝技能重写为蓄势、锋芒、护盾或团队增益；原 SP 被动也有对应替代。
三叠浪与一字千钧只提高伤害、持续伤害、治疗类产出，不提高护盾、攻击增益或锋芒充能。
墨契效果已经计入技能面板的伤害预览。

## 三战之间

每站有稳路与险路，先看完整敌方阵容，再做选择。前两站胜利后，稳路取一件墨契，险路可取两件。
末站胜利完成远征；走末站险路会取得「破阵归人」称号。

胜利时按每人剩余生命比例保留伤势，阵亡同伴以 25% 生命归队。
营地可回复 35% 最大生命，或保留伤势、换取后续全队攻击 +8%。
选择「第四笔」等修改最大生命的墨契时，伤势比例保持不变。

共有十种墨契：三叠浪、一字千钧、留白成壁、第四笔、起笔无痕、双锋、磨墨石、旧伞、回春帖、残卷。
其中「双锋」把普通攻击改成两次 65% 威力的攻击，每段独立积累锋芒。

路线种子决定路线与奖励抽取；刷新不会重抽。种子相同并采用相同选择，可以复刻同一构筑路线。
存档是浏览器本地存储；关掉网页可以继续。战斗内每一招不单独存档，中断后从该战起点恢复。
远征有自己的完成次数与旅程总结，不混入经典战斗的分享记录。

## 校准与验证

使用 `node tools/expedition-check.mjs 180` 对三档决策噪声各跑 180 条相同种子的旅程，
总计 **540 条旅程、1,576 场战斗**，超时 **0**，平均每战 **12.47 / 12.69 / 12.79 轮**。
三档通关数分别为 **156 / 138 / 131**。噪声表示对 AI 决策评分的扰动，不代表实测人类水平。
这组检查固定走稳路、选择治疗营地，并使用相同奖励优先顺序；不代表所有险路与构筑都已穷举平衡。

最终采用的调整是弓手队以守卫替换拳师，配合鼓姬形成架盾打法；远征医仙主动治疗为原来的 85%。
零噪声下三个队伍各 60 条固定种子的通关数从 **52 / 59 / 35** 收敛到 **55 / 55 / 46**。
原始统计保存在 `expedition-validation.json`。

规则测试覆盖三墨预算、每人一次、第四笔、起手折扣、连携倍率精度、无副作用预览、护盾只结算一次、
角色数据不被修改、扰乱条件、状态每轮只衰减一次、合法 AI 选择和完整行动账本。
旅程测试覆盖确定性奖励、重复结算拒绝、精英两次奖励、伤势恢复、失败终止和坏存档校验。

全仓库 **448 项测试通过**。经典对战另跑 4,000 局，平均 20.2 轮、超时 0，采样极差 9.3%。
浏览器真实旅程「墨路实测」走过纸灯夜渡、精英竹影试锋、精英落日问剑，分别在 9、9、6 轮获胜。
手动验收覆盖取消目标不扣墨、已出手角色锁定、余墨护盾、刷新恢复、伤势与休整、双奖励、起手折扣和 390px 窄屏。
测试过程中修复净化白光颜色导致 Canvas 报错，以及单体治疗把过量治疗计入统计的问题。

浏览器验收台：`tools/expedition-browser.html`。按钮明确启用玩家代理后，代理通过真实的选人、技能和目标控件操作，
不修改生命、不伪造战果；路线、奖励和营地仍由测试者选择。可切换 390px 的真实 iframe 视口进行窄屏检查。
验收台仅用于开发，游戏主入口不载入其代理脚本。

## 代码入口

- `src/core/ink-turn.js`：技能转换、共享墨量、连携、留白。
- `src/ai/ink-ai.js`：对合法的角色与技能组合评分，考虑墨耗、后续接力、击杀与护盾价值。
- `tools/ink-sim.js`：使用同一套墨量规则及已有技能执行器的模拟入口。
- `src/core/expedition.js`：旅程状态、路线、抽取、伤势与战前修改。
- `src/game/expedition.js`：持久化与页面流程。
- `src/game/battle.js`：实际回合、技能动画与旅程结算；使用可取消的延迟回调，避免旧战斗影响新战斗。
- `src/view/expedition-view.js`、`expedition.css`、`ink-hud.js`、`ink-hud.css`：地图、构筑与战斗提示。
