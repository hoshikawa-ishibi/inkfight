# docs · 导航

**三类东西，分三个地方放：**

| 放哪 | 装什么 | 什么时候搬走 |
|---|---|---|
| `docs/` 根目录 | **还在推进的计划** + 长期参考 | 计划做完 → `archive/` |
| `docs/workflow/` | **照着做的步骤书**（新增场景 / 角色小人） | 长期有效，不会做完 |
| `docs/archive/` | 已收尾或已放弃的计划 | 不再搬走，但值得翻回来查当时的推理 |

约束和铁律**不在这里**，在根目录 `CLAUDE.md`——那份每次会话都会整份读进上下文。
新增或修改工作约定只改 `CLAUDE.md`，不要往这里抄。
