# 墨境角色模型

`bladedancer.glb`（刀娘）与 `raven.glb`（墨鸦）是本轮导出样例。
完整 16 人可从游戏首页的「3D 造物间」分别下载。

模型由 `src/view/fighter-model.js` 的原创几何构造生成；共享现有角色的颜色、体型和武器配置。
GLB 包含无贴图的 PBR 材质、独立关节与武器节点，导出的是静止姿态，不包含蒙皮骨骼或动画片段。
游戏中的待机、出手、受击、倒地由 `poseFighter` 与战场事件驱动。

`validation.json` 是 Khronos glTF Validator 2.0.0-dev.3.10 对全部 16 人的独立验证结果。
每个模型均为 0 错误、0 警告；信息级提示仅建议省略默认变换矩阵。
验证通过不等于已经在所有第三方建模软件中逐一打开验收。

源代码、样例模型可继续随项目修改。Three.js 引擎采用其单独的 MIT 许可。
