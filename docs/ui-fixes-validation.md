# 页面与战斗信息修复验收

2026-09-05，针对用户在全屏浏览器的五条实际反馈修复。起点：`92c46ec`。

## 根因与改动

1. 首页原来将正文作为居中 flex 子项，立绘却按整个窗口右侧定位。现在正文与立绘共用居中、等宽双栏容器；人物条也使用同一宽度边界。
2. 远征页面的 `#screen-expedition.expedition-root { display:flex }` 覆盖了通用页面隐藏规则。移除 active 后它仍占位，导致战斗落在下方。现在切换统一更新 hidden/inert/active，非活动页面不能占布局，初始 HTML 也明确隐藏其他页面。
3. 战报此前绝对定位在被旧页面占据的文档上方。现在使用固定于当前视口的“战斗记录 / 角色详情”面板，按钮同步展开状态，提供关闭、遮罩和 Escape 路径，直接展示记录内容。
4. 锋芒从隐藏情报移到队员卡与技能附近：当前值/100、每击积累、100 点重击 ×1.5、哪些招式将触发重击，以及多段中的具体段数。非攻击技能不会误标重击。
5. 远征核心原先没有提前结束，问题是每关胜利都称“此路已破”。现在前两关明确已完成 x/3 和奖励/营地/下一关；第三胜才称完整通关。结算的下一步按钮移到统计上方。首页继续入口也与保存阶段一致。

战斗数值与原有 AI 立绘未改。
