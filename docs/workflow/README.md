# docs/workflow · 照着做的步骤书

**这个目录只放「要动手时照着走一遍」的流程。** 和 `docs/` 里的计划书分工明确：

- **计划**（`docs/*_PLAN.md`）回答「要不要做、为什么这么做」——做完就进 `archive/`
- **流程**（本目录）回答「现在要做，第一步是什么」——**长期有效，不会做完**

以后每加一类「新增 X 的时候该怎么走」，都放这里，不要散到 `docs/` 根目录去。

| 文件 | 什么时候打开 |
|---|---|
| `SCENE_WORKFLOW.md` | 新增 / 替换**场景**：生成模板、接入 `SCENES.art`、压缩、测试与浏览器验收 |
| `CHARACTER_WORKFLOW.md` | 新增 / 修改**角色小人**：视觉身份证、接入步骤、预览与测试标准 |

新增角色以 [当前方向](../DIRECTION.md) 和实际共享墨规则为准。旧角色设计思路保留在 [历史阵容计划](../archive/ROSTER_PLAN.md)，其中旧数值与流程不作为当前约束。
